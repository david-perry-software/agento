# Agento

Agento is a VS Code dashboard and command launcher for the Agento delivery workflow.
This scaffold contributes the Agento activity-bar container, refresh command, and
output channel. Delivery views and command routing arrive in later releases.

## Settings

- `agento.nodePath` selects the Node.js executable used for the bundled CLI.
- `agento.refreshDebounceMs` controls the watcher debounce and cannot be less than
	3000 milliseconds.

The CLI modules under `cli/` are generated byte copies of the repository's
`scripts/` modules. Run `npm run copy-cli` after changing those sources. In this
bundle, the CLI's `PLUGIN_ROOT` resolves to `extension/`; commands that return paths
to plugin prompt files are therefore informational and must not be used for command
dispatch by the extension.

## Development

Run `npm ci`, `npm run build`, `npm run test:unit`, `npm run test:electron`, or
`npm run package` from this directory. Packaging also validates the VSIX runtime
contents and confirms that VSCE's `extension/LICENSE.txt` entry is byte-identical to
the generated `extension/LICENSE` source.
